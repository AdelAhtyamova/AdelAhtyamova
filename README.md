### Всем привет! 
Я являюсь начинающим аналитиком данных. Работала в Центре реабилитации и реинтродукции диких птиц "Воронье гнездо" куратором городского стационара. 
Интерес к аналитике сформировался во время работы с учётными данными в НКО. Возникло желание провести анализ данных для оптимизации работы фонда. 
Это вдохновило меня на целенаправленное развитие в сфере аналитики данных.

Владею следующими навыками:
- SQL: оконные функции, подзапросы, операторы JOIN.
- Python для исследовательского анализа данных с использованием библиотек pandas, matplotlib, seaborn.
- MS Excel: функции, формулы, сводные таблицы.
- Написание SQL-запросов в DBeaver.
- Анализ данных и их визуализация в Jupyter Notebook.
- Разработка дашбордов в Tableau и DataLens.
- Проведение A/B тестов.

Мной был пройден курс на "Аналитика данных" от Яндекс Практикума. В данный момент совершенствую свои навыки на курсе "Симулятор SQL" от Karpov.Courses.
Постоянно учусь новому, стремлюсь повышать уровень своих технических и аналитических навыков.
