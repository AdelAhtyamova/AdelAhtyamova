### Всем привет! 
Я являюсь начинающим аналитиком данных. Работала в Центре реабилитации и реинтродукции диких птиц "Воронье гнездо" куратором городского стационара. 
Интерес к аналитике сформировался во время работы с учётными данными в НКО. Возникло желание провести анализ данных для оптимизации работы фонда. 
Это вдохновило меня на целенаправленное развитие в сфере аналитики данных.
